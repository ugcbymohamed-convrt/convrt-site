# CONVRT site — notes for Claude Code

- Stack: React 18 + Vite + Tailwind, deployed on Vercel. Tests: `node --test tests/*.test.mjs`. Build: `npm run build`.
- **Blog (The CONVRT Blog):** to add or change an article, edit `src/content/blog/<slug>.md` only — follow
  `docs/blog-publishing.md`. Never hard-code article lists in the page components, never invent authors, dates or
  article content, and keep `status: draft` until the user says to publish. The `/blog` index stays
  `noindex, follow` until the user approves flipping `BLOG_INDEXABLE` (and removing the `vercel.json` header).
- Do not touch the lead-generation forms, MailerLite integration (`api/_lib/subscribe.js`) or Resend notifications (`api/_lib/notify.js`) unless asked.
- Never push to `main` or deploy to Production without the user's explicit approval; feature branches get a Vercel Preview.
- **Pricing, policies and structured data:** prices, usage-rights terms, FAQ answers and JSON-LD all come from `src/seo/businessKnowledge.js` (see `docs/business-knowledge-and-structured-data.md`). Edit the data there, never retype a price in a component; keep currencies exactly as supplied and never invent facts (counts, ratings, locations, results).
- **Portfolio videos (Spanish ones: `languages: ['es']` + `onlyIn: ['es']`, `docs/multilingual-spanish-videos.md`):** every video on `/creator-showcase`, `/ugc-video-agency` and the homepage client panels lives in ONE file, `src/content/portfolio.js` (how-to in its header and `docs/creator-showcase-page.md`). Add a video there once, classified by `industry`; never copy a video into a page component. Never set `portfolioUse` / `creatorConsent` to `true`, or invent an `uploadDate`, an industry (use `'unclassified'`), a title or a production credit, unless the user has confirmed it. `/creator-showcase` is the **Creator Showcase** of independent creators' examples: never call those videos CONVRT productions.
- **Spokesperson page:** `/spokesperson-video-production` reuses the UGC page's configuration-driven components with its own content (`src/content/spokespersonPage.js`, `docs/spokesperson-video-page.md`). Its videos are the `type: 'spokesperson'` entries in `src/content/portfolio.js`; never use UGC videos or the UGC page's Elyon proof there, and never invent a spokesperson price, result or testimonial.
- **Organic Social page:** `/social-media-video-production` reuses the same configuration-driven components with its own content (`src/content/organicSocialPage.js`, `docs/organic-social-video-page.md`). Its videos are the `type: 'organic'` entries in `src/content/portfolio.js` (none yet; the page is `noindex` until one is approved); never use UGC, spokesperson or homepage-client (`type: 'social'`) videos there, never assign a content `style` to a video unless the owner confirmed it, and never invent a package quantity, response time, result or testimonial. The only organic proof is the published Graspo case study.
- **SaaS page:** `/saas-video-production` reuses the same configuration-driven components with its own content (`src/content/saasPage.js`, `docs/saas-video-page.md`). Its videos are `type: 'saas'` entries, or entries that list `alsoOn: { saas: ... }`, in `src/content/portfolio.js` (none yet; the page is `noindex` until one is approved); never use UGC, spokesperson, organic or homepage-client videos there, never assign a `format` or `production` credit unless the owner confirmed it, and never invent a SaaS price, turnaround, deliverable, result or testimonial (SaaS demos and explainers are custom-scoped).
- **SEO/GEO Batch 2 (Nov 2026, `docs/seo-geo-batch-2.md`):** the four core services have ONE stable JSON-LD `@id` each (`serviceId(slug)` = the service page's `#service`) defined from `CORE_SERVICES`; every public claim, figure and client relationship is listed in `PUBLIC_CLAIMS` (`businessKnowledge.js`), so edit it there and never silently change a number. Organic CTAs all read `ORGANIC_CTA` (the strategy call), never the paid-ads Roadmap. Case-study schema has no Article, ratings or dates. Do not publish a faceless / hands-only UGC claim until the owner confirms the format is offered.
- **Languages (en · es · fr · ar):** English URLs never change. Translations live under `/es/`, `/fr/`, `/ar/` and exist only for pages listed in `src/i18n/registry.js`; `src/i18n/locales.js` says which languages are live. Architecture, the add-a-language steps and the blocked conversion flows are in `docs/multilingual-architecture.md`; the Spanish release state and the owner's open decisions are in `docs/multilingual-spanish-release.md`. Rules: wrap English UI text in `tr('…')` (never at module load; use `<T>` there), keep English strings the source of truth (the Spanish dictionary is keyed by the exact English sentence, so changing English copy fails the build until `src/i18n/es/dict-*.js` is updated), never translate a client quote, never hard-code a price in any language: English uses `money()` / the business data (USD); Spanish shows its own owner-approved EUR amounts from `src/i18n/es/pricing.js` (`docs/multilingual-spanish-eur-pricing.md`): never convert, never reuse a USD number, never type an amount in the Spanish dictionary (use `{{price:key}}` tokens), never route a translated page into an English-only form (`src/i18n/cta.js`; only the Roadmap is translated so far), and do not publish a language until every page, FAQ, JSON-LD block and the legal set it needs is complete. After touching shared components run `node scripts/i18n-english-parity.mjs <dist-before> <dist-after>`: English pages must differ only by the language selector and hreflang.
- **GEO Work Package 1 (Nov 2026):** how CONVRT produces and who it serves live in `PRODUCTION_MODEL` and `INTERNATIONAL_CLIENTS` (`businessKnowledge.js`, owner-approved wording, both in `PUBLIC_CLAIMS`). CONVRT is NOT remote-only: remote production through its creator network, on-location filming in Spain, other countries by arrangement; on-location filming is never presented as included in standard packages; never imply offices or local production teams outside Spain. The About page carries the full production sentence once; the Organization JSON-LD address is country-only (`BRAND.country`, `ES`). Do not add dialect or native-speaker claims to the English site.

- **Video posters (Nov 2026, `docs/video-thumbnails.md`):** the still frame shown before a video plays is chosen per Cloudflare Stream video, in seconds, in ONE file: `src/content/posterFrames.js`. Same-origin posters are re-exported from those frames by `python3 scripts/poster-frames.py`; Stream thumbnail URLs are built only through `streamPoster()`. Never hand-write a `thumbnail.jpg` URL or pick a frame by guesswork; add a new video's frame to the file (review ten candidates), then run the script. Spanish terminology: "creativos" for ad creatives (the one approved exception is the homepage headline "Creatividades diseñadas para conectar."), "Spokesperson" as the service name; the 10 free hooks have NO Spanish page: the hero card is a visible, non-clickable "Próximamente" block (`aria-disabled`, no link) until `LOCALIZED_FLOWS.es.hooks` is made true on purpose.
